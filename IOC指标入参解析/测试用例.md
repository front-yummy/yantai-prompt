### 用例 1-2:相对时间 + 无分组(fallback)

**输入:**
```
NME 厂,2026年7月,AA和3089充電蓋-黑色 机种,指标ID:2054753727827640321
```

**MCP 返回维度元数据(关键):** 组织维度 L2(廠別,值[NME,VNNME,VNWEP,WEP]);分析维度 機種(值含"AA"、"3089充電蓋-黑色");第一个组织维度条目为 L1(基地)。

**预期:** dateDim=月(2026-07-01~2026-07-31);orgDimList 一条(L2=NME);analyseDimList 一条(值["AA","3089充電蓋-黑色"]);分组 fallback 到 L1 基地。

**实际输出(v1.0,含推理过程,有问题):**
```
(模型输出了完整的"解析过程":时间维度/组织维度/分析维度/分组 的逐步推理,然后才给 JSON)
最终 JSON:
{
  "dateDim": "月",
  "startTime": "2026-07-01",
  "endTime": "2026-07-31",
  "indexId": "2054753727827640321",
  "levelCode": "1",
  "dimType": "组织维度",
  "groupByDim": "org_l1_name",
  "dimensionId": "2047201883577851906",
  "groupByDimValue": "",
  "orgDimList": [
    {"levelCode":"2","dimensionId":"2047201883577851906","orgDimCode":"org_l2_code","orgDimName":"org_l2_name","orgDimNameValues":["NME"]}
  ],
  "analyseDimList": [
    {"levelCode":"0","dimensionId":"2046878727545757697","analydim":"dim_table_1776848891857_l0_PRODUCT_NAME","analydimValues":["AA","3089充電蓋-黑色"]}
  ]
}
```

**结论:**
- ✅ JSON 内容正确:NME 命中 L2 廠別、分析值裁掉"机种"后正确匹配为 ["AA","3089充電蓋-黑色"]、分组 fallback 到第一个组织维度(L1 基地)。
- ❌ 格式问题:输出了大段推理过程,违反"只输出 JSON"。→ 触发 v1.1 修复(开头总纲+末尾强调+流程标注"不输出"+补机种同义词)。

**v1.1 复测结果:** 待平台覆盖后填入
