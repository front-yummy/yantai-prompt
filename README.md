# Agent Skills 索引

本目录存放各 skill 的提示词、修改记录、测试用例。各 skill 可作为子 skill 被其他 skill 调用。

> **新建/优化 skill 必读**:见 [SKILL_WORKFLOW.md](SKILL_WORKFLOW.md) -- 本目录的工作规范 + 踩坑经验库。核心用系统的 `skill-creator` skill 生成,落地遵循该规范。

## 子 Skill 清单

> 调用方在调用某子 skill 前,先查此表了解其功能、输入、输出。详细规则见各 skill 文件夹内的 `SKILL.md`。

| 中文名 | 功能 | 输入 | 输出 | 状态 | 目录 |
|---|---|---|---|---|---|
| 维度识别Skill | 把用户自然语言查询条件(时间、组织、分析维度、分组)+ 指标ID,组装成 IOC 指标入参 JSON | 用户表达、指标ID(平台自动调 MCP 取维度元数据、按需调当前时间 skill) | 指标入参 JSON(或补充信息的提醒文字) | 可用 | [维度识别Skill/](维度识别Skill/) |
| 设备异常分析 | 定位故障次数最高的线体、该线体下故障 Top3 设备及其计划外停机时长,合并成明细表 | 用户时间、组织、分析维度(内部调 维度识别Skill 子skill + 查指标数据MCP) | 设备异常分析结果(Markdown 表格) | 可用 | [设备异常分析/](设备异常分析/) |
| 获取当前系统时间 | 获取当前系统时间(东八区/上海时区) | 无 | 形如 `当前时间(东八区/上海时区)是:2026年7月28日 11:17:41` | 可用(外部已有) | — |

## 目录结构约定

```
Agent/
├── README.md                  # 本文件,子skill索引
├── _模板/                     # 新建skill用的模板,复制即用
│   ├── SKILL.md
│   ├── 修改记录.md
│   └── 测试用例.md
└── <skill中文名>/             # 每个skill一个文件夹
    ├── SKILL.md               # 提示词(最新版)
    ├── 修改记录.md            # 优化日志,倒序,追加式
    └── 测试用例.md            # 测试输入+实际输出+结论
```

## 维护规则

详细规范见 [SKILL_WORKFLOW.md](SKILL_WORKFLOW.md)。简要:

- **新增 skill**:用系统 `skill-creator` 生成,复制 `_模板/` 改名为 skill 中文名,填内容,在本表加一行。
- **优化 skill**:用 `skill-creator` 迭代,改 `SKILL.md` 后在 `修改记录.md` **顶部**追加记录,在 `测试用例.md` 追加测试结果。**先查 SKILL_WORKFLOW.md 的"踩坑经验库"避免重复踩坑。**
- **调用子skill**:先查本表了解功能,再看子skill 的 `SKILL.md` 了解输入输出格式。
