## 批次 2 (2026-08-03, v1.3)

### 用例 2-1:"本周"时间推算(验星期几)

**输入:**
```
查询 NME 厂,本周的产量,指标ID:2054753727827640321
```

**MCP 返回维度元数据(关键):** timeParticleList 含"周";组织维度 L2(廠別,值含NME)。

**预期:** dateDim=周;调当前时间子skill 拿到"今天+星期几";startTime=本周一(今天-(星期几-1)天),endTime=今天。

**实际输出(v1.2,错误):**
```
"dateDim": "周",
"startTime": "2026-08-24",
"endTime": "2026-08-30"
```
(startTime/end 错误,因为没拿到星期几,无法推算本周一)

**结论:**
- ❌ 本周推算错误。根因:当前时间子skill 返回没带"星期几"。
- → 触发 v1.3 修复:明确调用时拿"日期+星期+时间",并写清推算公式(本周一 = 今天 - (星期几-1)天)。

**v1.3 复测结果:** 待平台覆盖后填入

## 批次 3 (2026-08-03, v1.4)

### 用例 3-1:"本周"end 不超今天(强化约束)

**输入:**
```
查询 NME 厂,本周的产量,指标ID:2054753727827640321
```

**MCP 返回:** timeParticleList 含"周";组织维度 L2(廠別,值含NME)。
**当前时间子skill 返回(假设):** 2026年8月5日 星期三 ... (或当天实际日期)

**预期:** dateDim=周;start=本周一(今天-(星期几-1)天), **end=今天**(绝不是本周日/未来日期)。例:今天星期三 -> start=2026-08-03, end=2026-08-05。

**实际输出(v1.3,错误):**
```
"dateDim": "周",
end 算成了本周日(未来日期)
```

**结论:**
- ❌ v1.3 虽写"end=今天",模型仍按完整自然周算到本周日。-> 触发 v1.4:多处强措辞钉死 + 输出格式节加 endTime 约束。

**v1.4 复测结果:** 待平台覆盖后填入
