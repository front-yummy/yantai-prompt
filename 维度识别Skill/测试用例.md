## 批次 8 (2026-08-12, v1.9)

### 用例 8-1:"上周"时间推算(验上周一/上周日)

**输入:**
```
查询 NME 厂,上周的产量,指标ID:2054753727827640321
```

**MCP 返回维度元数据(关键):** timeParticleList 含"周";组织维度 L2(廠別,值含NME)。
**mcp(system_time) 真实返回:** {"datetime": "2026-08-12T13:03:12.052943+08:00", "timezone": "CST", "unix_timestamp": 1786510992}

**预期:** dateDim=周;星期几=3 -> 本周一=2026-08-12-2天=2026-08-10;上周一=2026-08-10-7天=2026-08-03,上周日=2026-08-10-1天=2026-08-09。
- startTime=2026-08-03,endTime=2026-08-09

**关键校验点:**
- end 必须是上周日(2026-08-09),不能截到今天(2026-08-12),也不能算成本周一(2026-08-10)
- start 必须是上周一(2026-08-03),不能与上周日挨着错位

**v1.9 复测结果:** ❌ 模型输出 startTime=2026-08-04,endTime=2026-08-10,整体晚1天(正确应 08-03~08-09)。根因:星期三被取成星期二。-> 触发 v1.10:展开星期编码 + 加自检校验。

### 用例 8-1b:"上周"v1.10 复测

**输入:** 同 8-1(查询 NME 厂,上周的产量)
**mcp(system_time) 真实返回:** {"datetime": "2026-08-12T13:03:12.052943+08:00", "timezone": "CST", "unix_timestamp": 1786510992}

**预期(v1.10):** 星期几=3 -> 本周一=2026-08-10 -> 上周一=2026-08-03,上周日=2026-08-09。
- startTime=2026-08-03,endTime=2026-08-09

**关键校验点:**
- end(08-09) 必须早于本周一(08-10)
- end(08-09) 不能等于今天(08-12)
- start(08-03) 必须是周一,不能是周二(08-04)

**v1.10 复测结果:** 待平台覆盖后填入


### 用例 8-1c:"上周"v1.11 复测(mcp 真实返回)

**输入:** 同 8-1(查询 NME 厂,上周的产量)
**mcp(system_time) 真实返回:** {"datetime": "2026-08-12T13:03:12.052943+08:00", "timezone": "CST", "unix_timestamp": 1786510992}

**预期(v1.11):**
- 今天日期 = datetime 前10位 = 2026-08-12
- 星期几:mcp 不返回,自己算。2026-08-12 距 2026-01-01 = 223天,223 mod 7 = 6,2026-01-01 是星期四,星期四+6 = 星期三,星期几=3
- 本周一 = 2026-08-12 - (3-1) = 2026-08-10
- 上周一 = 2026-08-10 - 7 = 2026-08-03;上周日 = 2026-08-10 - 1 = 2026-08-09
- startTime=2026-08-03,endTime=2026-08-09

**关键校验点:**
- 禁止用 JS getDay()(周日=0),那是 v1.10 及之前上周算错1天的根源
- end(08-09) 必须早于本周一(08-10),且不等于今天(08-12)

**v1.11 复测结果:** 待平台覆盖后填入
